From the first message to the diff.

  1. Open the project

    Use a small example repository on disk. Check its starting state so you can distinguish existing edits from the task’s changes.

  2. Choose the connection and write the brief

    Select an available agent or local model. For Claude Code and Codex, check the chosen account. Ask for durations above one hour to use hours and minutes, and request tests.

  3. Follow the activity

    Read the agent’s steps and any request for input. When a command needs permission, inspect the command and its scope before allowing or denying it.

  4. Inspect the changes

    Open the changed files and read the diff. Check the duration examples yourself and run the project’s relevant tests before accepting the result.

When the task stops

Answer a request for input in the conversation. Review a pending permission request before continuing. If the result needs another pass, describe the remaining problem and inspect the next diff. Resume and Undo depend on the runtime and supported operation.
