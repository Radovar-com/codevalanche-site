Where your code goes

Clear boundaries, stated plainly.

Codevalanche keeps the workspace on your machine. What leaves it depends on the agent you pick, and you can see that choice for every task.

01

Your repository stays on disk.

Agents work on the project you opened. There is no upload step and no copy of your code on our servers.

02

Cloud agents receive context.

A hosted model receives your prompts and the file context it needs for the task. The provider you choose sets those terms.

03

Local models stay local.

A supported local model runs on your own hardware, so the task does not need a cloud provider.

04

Permission modes have boundaries.

Approval behavior depends on the agent and its mode. Some modes can write files directly; review and Undo have their own limits.

What is Codevalanche?

A desktop app for Windows for coding with AI agents. It opens a project on your computer, lets you give a task to an agent or a local model, keeps the conversation for each task together and shows the changed files and diffs for review. It is made by Radovar.

How is it different from using Claude Code or Codex directly?

Claude Code and Codex are agents. Codevalanche is the workspace around them: your projects, the choice of agent or local model for each task, the conversation that guided the work and the review of what changed, in one window.

Which agents and accounts can I connect?

Your installed build determines the supported integrations. Claude Code and Codex support separate connected accounts; local models and API providers have different setup requirements.

Do I need a Codevalanche account?

No. You can use the app as a guest. A Codevalanche account lets you sign in on the desktop app and manage your profile and sessions on this website.

Does my code leave my computer?

Your repository stays on disk. A hosted model can still receive prompts and relevant file context, so the provider and runtime you choose determine those boundaries. A supported local model runs on your own hardware.

Which platforms are supported?

Codevalanche is built for Windows. No public macOS or Linux download is currently offered. Check the release page for qualified availability.

When can I download it?

Codevalanche is in early access for Windows, and public downloads are in preparation. This page will carry them as soon as they ship.
