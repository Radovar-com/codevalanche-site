Where your code goes

Clear boundaries, stated plainly.

The workspace stays on your machine. What leaves it depends on the agent you pick, and you see that choice for every task.

Security and data boundaries
01Your repository stays on disk

Agents work on the project you opened. There is no upload step and no copy of your code on our servers.

02Cloud agents receive context

A hosted model receives your prompts and the file context it needs for the task. The provider you choose sets those terms.

03Local models stay local

A supported local model runs on your own hardware, so the task does not need a cloud provider.

04Permission modes have boundaries

Approval behavior depends on the agent and its mode. Some modes can write files directly. Review and Undo have their own limits.

Questions

Questions and answers. Before you download.

What is Codevalanche?

A desktop app for Windows for working with AI agents. It opens a project on your computer, lets a Coordinator or a single agent do the work, and shows you every change for review. It is made by Radovar.

How is it different from using Claude Code or Codex directly?

They are agents. Codevalanche is the workspace around them: your projects, the Coordinator, the choice of agent or local model for each task, and the review of what changed, in one window.

Which agents and accounts can I connect?

Claude Code and Codex with your own accounts, more than one of each if you want. Other agents and API keys in Your AIs, or a local model that runs on your PC.

Do I need another AI subscription?

No. Use your Claude or ChatGPT plan, an API key, or a local model.

Do I need a Codevalanche account?

No. You can use the app as a guest. An account lets you sign in on the desktop app and manage your profile and sessions on this website.

Does my code leave my computer?

Your repository stays on disk. A hosted model receives prompts and the file context it needs, on your provider's terms. A local model keeps the task on your PC.

Which platforms are supported?

Windows 11, 64-bit. The Mac and phone apps are on their way.

When can I download it?

Now. After you install it, Codevalanche updates itself.
