Questions, answered

A clear product deserves a clear boundary.

What is Codevalanche?+

Codevalanche is a local-first desktop workspace that connects coding agents to real projects on your machine and keeps the work visible from prompt to review.

Does Codevalanche replace my coding agent?+

No. It provides the surrounding project, task, permission, process, and review layer while the selected coding-agent runtime keeps its own account and model behavior.

Can I connect more than one account of the same provider?+

Yes. Accounts are first-class in Codevalanche. You can keep, for example, a personal and a work Claude subscription connected at the same time, see each account's usage separately, and choose which one a task runs on.

Where does my repository live?+

The initial product is designed around the repository you already have on disk. It does not require an upload step to begin working.

Is Codevalanche available to download?+

The download section on this page lists every platform build and its current state. The first public builds are in preparation, and the buttons activate the moment they ship.
