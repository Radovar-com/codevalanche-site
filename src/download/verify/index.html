Before you install

Verify your Windows download.

The installer has no Windows code-signing certificate. Here is how to check the file and understand the warning.

Back to downloads

1. Check the file.

In File Explorer, open the folder containing the EXE. Click the address bar, type powershell and press Enter. Paste the command for your version below.

Compare the result with the SHA-256 shown here, ignoring letter case. Every character must match. If it differs, do not run the file; delete it and download it again from this site.

A matching hash confirms the file matches this published installer. It does not prove the software is harmless or identify its publisher.

2. Understand the Windows warning.

Windows SmartScreen may show “Windows protected your PC” because this EXE has no code-signing certificate and SmartScreen may not recognize it. The SHA-256 check does not remove that warning.

Only continue if the hash matches and you trust this download.

  1. Open the checked EXE. On “Windows protected your PC”, select “More info”.
  2. Check that the file name matches your download. “Unknown publisher” is expected for this unsigned installer. Select “Run anyway” if you choose to continue.
  3. If Windows asks whether to allow changes to your device, approve only if you want to install this app.

If “Run anyway” is missing or your organization blocks the app, stop and contact your administrator. Do not turn off Windows security protections.
