Install with confidence.

Windows may warn you the first time.

Codevalanche is new and the installer is not yet signed with a company certificate, so Windows SmartScreen can show “Windows protected your PC”. Click “More info”, then “Run anyway”. The app’s own updates are signed and checked before they install.

What you need

  • Windows 11, 64-bit.
  • For cloud agents: an account with Anthropic (Claude Code) or OpenAI (Codex), or a Gemini API key for Gemini CLI.
  • For local models: the more memory, the bigger the model. The app checks each model against your PC before you download it.
  • Microsoft WebView2 is installed automatically if it is missing.

Release history

Codevalanche updates itself, so the latest installer is all you need.

Before you install.

Do I need a website account to read the guides?

The product walkthrough and setup guidance are public. Agent authentication is separate from the website account.

What do I need to run an agent?

A supported connection and your own provider account, or a supported local model with suitable machine resources. Some coding agents require an external runtime.
