Security and data boundaries

Know what stays local. Know what you connect.

Your project, the selected provider and the active tools each have a role. Check those boundaries before you start a task.

Files, inference and credentials.

Repository on disk
The desktop workspace opens your local project. Files can be changed by agent operations; review the actual diff and keep appropriate backups or version history.
Cloud agents
Using a cloud agent can send task context and relevant project content to that provider. Its own account terms and data practices apply.
Local inference
Inference runs at the configured local runtime or server. Downloads, tools and external endpoints can still access the network.
Provider credentials
Claude Code and Codex support separate account configuration. Treat provider credentials as sensitive and verify the chosen account before working.

The Codevalanche website account is separate from agent authentication. Signing in on the website does not connect a provider account in the desktop app.

Permission, review and recovery.

Check the active permission mode

Approval behavior varies by runtime and configuration. A command request describes one operation; it is not a universal guarantee that every write waits for permission.

Inspect changes after execution

Read the diff and verify the behavior independently. Supported Undo operations have guards and limits; do not assume every filesystem or external action can be reversed.

Browser and remote access

The embedded browser is a workspace surface. Remote access is a separate capability with its own setup and qualification. Android remains a separately qualified preview, not a generally available remote-access product.

Report a security issue.

Found a weakness in Codevalanche? Tell us privately first. We read every report, fix real problems and thank the people who find them.

What you can report

Desktop app
The latest released version of Codevalanche for Windows.
Installers and updates
The installers we publish and the update feed the app downloads.
Website and accounts
codevalanche.com, including the account pages.

Not covered here

Other companies’ tools
Problems in Claude Code, Codex or another provider’s own tool or service. Please report those to that provider.
Services we use
Problems in GitHub, Cloudflare or other services, unless our own setup causes them.
Attacks on people or availability
Phishing, social engineering, denial of service, spam, or access to anyone else’s account or data.
Reports without impact
Scanner output without a working proof, or a missing best practice that does not put anyone at risk.
Known limits
The Windows warning shown for our installer, which is not yet code-signed.

How to report

Write to the address below. Include the app or website version, the steps to reproduce the problem and what an attacker could do with it.

Do not send passwords, tokens or private code. If you need to show data, use test data you created yourself. You can write in English or Romanian.

security@radovar.com

What we promise

A first reply
We confirm that we received your report within 5 working days.
Updates until it is fixed
We tell you whether we can reproduce the problem and keep you informed until the fix is released.
Fix times
We aim to fix serious problems within 30 days and other confirmed problems within 90 days.
Disclosure
Please wait until the fix is released, or 90 days, before you publish details. We can agree on another date together. Security fixes are noted in the changelog.

Good-faith research

If you follow these rules, we will not take legal action against you. Test only on your own computer and your own accounts. Stop as soon as you reach data that is not yours, and do not keep it. Do not harm our service or other people.

Rewards

We do not pay money for reports at this time. With your permission, we thank you by name on this page.
