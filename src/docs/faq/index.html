    Steps

    1. Do I need a Codevalanche account?

      No. You can use the app as a guest. A Codevalanche account lets you sign in on the desktop app and manage your profile and sessions on this website.

    2. Which agents and accounts can I connect?

      Claude Code and Codex with your own accounts, more than one of each if you want. You can also use Gemini CLI with your own API key, or a supported local model that runs on your PC.

    3. Does my code leave my computer?

      Your repository stays on disk. A hosted model can still receive prompts and relevant file context, so the provider and runtime you choose determine those boundaries. A supported local model runs on your own hardware.

    4. Can I resume or undo any operation?

      Resume depends on the runtime and retained conversation state. Undo is available only for supported guarded operations; inspect the current files before retrying or reverting.
