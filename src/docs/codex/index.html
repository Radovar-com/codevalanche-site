    Steps

    1. Open AI Providers in Settings and choose the OpenAI connection for Codex. Complete the offered account sign-in, return to Codevalanche and check the connection status. Select that account for the task before sending the brief.

    2. If sign-in is unfinished or the runtime is missing, resolve that setup state before starting work. Follow the setup guidance for your installed build; provider authentication can change.

    3. Keep separate Claude Code and Codex accounts connected, then choose the account for a run. No pooled subscriptions or automatic account rotation.
