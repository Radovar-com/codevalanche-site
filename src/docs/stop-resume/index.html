    Steps

    1. Use Stop to interrupt the current answer, then inspect the files before continuing.

    2. Answer a request for input in the conversation. Review a pending permission request before continuing. If the result needs another pass, describe the remaining problem and inspect the next diff. Resume and Undo depend on the runtime and supported operation.

    3. Resume depends on the runtime and retained conversation state. Undo is available only for supported guarded operations; inspect the current files before retrying or reverting.
