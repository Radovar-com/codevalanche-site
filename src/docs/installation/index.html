    Steps

    1. Windows 11, 64-bit.

    2. Open the installer from your Downloads folder. If Windows SmartScreen appears, choose “More info”, then “Run anyway”.

    3. Codevalanche is new and the installer is not yet signed with a company certificate, so Windows SmartScreen can show “Windows protected your PC”. Click “More info”, then “Run anyway”. The app’s own updates are signed and checked before they install.

    4. Microsoft WebView2 is installed automatically if it is missing.
