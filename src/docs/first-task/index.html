    Steps

    1. Use a small example repository on disk. Check its starting state so you can distinguish existing edits from the task’s changes.

    2. Select an available agent or local model. For Claude Code and Codex, check the chosen account. Ask for durations above one hour to use hours and minutes, and request tests.

    3. Read the agent’s steps and any request for input. When a command needs permission, inspect the command and its scope before allowing or denying it.

    4. Open the changed files and read the diff. Check the duration examples yourself and run the project’s relevant tests before accepting the result.
