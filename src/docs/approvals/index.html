    Steps

    1. Check the active permission mode before a task. Some operations ask for approval; behavior varies by agent and configuration. Review changed files even after approving a command.

    2. Read the agent’s steps and any request for input. When a command needs permission, inspect the command and its scope before allowing or denying it.

    3. Open the pending request and inspect its command and scope. Allow or deny it deliberately; waiting is not proof of a stalled runtime.

    4. Approval behavior depends on the agent and its mode. Some modes can write files directly; review and Undo have their own limits.
