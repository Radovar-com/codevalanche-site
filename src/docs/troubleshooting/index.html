    Steps

    1. Install Claude Code using its provider’s instructions, then open the Anthropic connection in AI Providers. Complete sign-in and check that Codevalanche detects the runtime and account. Choose the account and permission mode for the task.

    2. Finish the provider’s authentication flow and check connection status. Website sign-in does not connect an agent account.

    3. Read the provider’s message and account limits. Account quotas are separate; switching or handoff is an explicit decision.

    4. Open the pending request and inspect its command and scope. Allow or deny it deliberately; waiting is not proof of a stalled runtime.

    5. Check server reachability, the loaded model and the configured endpoint. Then check memory and model compatibility.

    6. Describe the setup step, runtime and visible error. Remove credentials and private project content from screenshots or logs.
