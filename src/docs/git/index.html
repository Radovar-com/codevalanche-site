    Steps

    1. Use a small example repository on disk. Check its starting state so you can distinguish existing edits from the task’s changes.

    2. Before a Git commit, inspect the diff and run your project’s checks. Commit only the files you intend to keep.

    3. Read the changed files and run the checks before deciding what belongs in your project.
