    Steps

    1. Open the changed files and read the diff. Check the duration examples yourself and run the project’s relevant tests before accepting the result.

    2. Inspect each changed file, run the relevant project checks and verify the requested behavior. Treat the assistant’s summary as guidance to verify.

    3. Resume depends on the runtime and retained conversation state. Undo is available only for supported guarded operations; inspect the current files before retrying or reverting.
